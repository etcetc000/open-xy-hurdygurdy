Original instrument author: [SammiBabe666](https://github.com/SammiBabe666),
identified by the repository owner. Instrument authorship credit belongs to
SammiBabe666; this repository contains the SDK migration and subsequent
optimization work.

Archive SHA-256: `e21bc461aad517d71139c3d093a813e67aa019c2dc4df88997029ebdf916c749`.

Original path: `Hurdy Gurdy for OP-XY/engine/machines/hurdygurdy/`.
The initial commit preserves those source files byte for byte.
No license or author attribution file was supplied in the archive. On
2026-10-24, the repository owner confirmed permission to make this source
repository public and publish the machine through the Open-XY catalog.
See [LICENSE](LICENSE) for that permission record. No license is inferred
from the SDK's license. The archive did not document the friction-table
provenance; the audit retains that finding.

The standalone player, installer, PDFs, recordings and preset files remain
outside this source repository. The twelve parameter presets in
`definition.json` are part of the imported machine source.
